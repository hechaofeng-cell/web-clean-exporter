二、 核心考点与典型试题

1. 切线方程与几何意义

【第1题】 已知函数 f(x) = x³ - 3x² + 2x + 1，求曲线 y = f(x) 在点 (1, f(1)) 处的切线方程。

解析： 对函数求导得 f'(x) = 3x² - 6x + 2。将 x = 1 代入得切线斜率 k = f'(1) = 3 - 6 + 2 = -1，且 f(1) = 1。因此切线方程为 y - 1 = -(x - 1)，即 x + y - 2 = 0。

2. 函数图像与极值分析（含图示）

【第2题】 观察下方三次函数 f(x) = x³ - 3x 的函数图像示意图，指出其极大值点与极小值点：

解析： 令 f'(x) = 3x² - 3 = 3(x + 1)(x - 1) = 0，解得驻点 x₁ = -1, x₂ = 1。当 x ∈ (-∞, -1) 时 f'(x) > 0；当 x ∈ (-1, 1) 时 f'(x) < 0；当 x ∈ (1, +∞) 时 f'(x) > 0。故函数在 x = -1 处取得极大值 2，在 x = 1 处取得极小值 -2。

3. 导数压轴综合解答题

【第11题（15分）】 已知函数 g(x) = a·ln(x) + x² - 2x（其中 a ∈ R）。
（1）讨论函数 g(x) 的单调区间；
（2）若对于任意 x ∈ [1, +∞)，不等式 g(x) ≥ -1 恒成立，求实数 a 的取值范围。

答案提示： （1）定义域为 (0, +∞)，导函数 g'(x) = (2x² - 2x + a) / x，按判别式 Δ = 4 - 8a 分类讨论 a ≥ 1/2、0 < a < 1/2 及 a ≤ 0 三种情况即可；（2）实数 a 的取值范围为 [0, +∞)。
