# 📥 网页长文/试卷纯净提取与一键导出工具 (CleanReader & Exporter)

一款基于原生 JavaScript (ES6+) 开发的 Tampermonkey（篡改猴）浏览器脚本，用于提取网页中已加载的正文、长文与在线试卷内容，自动过滤导航栏、侧边栏、广告、AI 助手与统计分析弹窗，并以清爽无框线的白底 A4 排版一键导出为 **PDF**、**Word (`.doc` / `.docx`)** 或调用**系统高清矢量打印**。

---

## 📁 项目文件说明

- `web-clean-exporter.user.js`：完整油猴脚本源码（可直接安装到 Chrome / Edge 的 Tampermonkey 插件中）。
- `demo-test.html`：本地离线体验与联调测试页（双击用浏览器打开即可直接体验，无需安装插件）。
- `README.md`：详细安装、配置与使用指南。

---

## 🛠️ 一、安装与配置详细步骤

### 第一步：在 Chrome / Edge 中安装 Tampermonkey（篡改猴）
1. 打开 Chrome 或 Microsoft Edge 浏览器，进入浏览器扩展商店搜索并安装 **Tampermonkey**（篡改猴）。
2. **重要权限设置（新版 Chromium 内核浏览器必做）**：
   - 在浏览器地址栏输入 `chrome://extensions/`（Edge 浏览器输入 `edge://extensions/`）并回车。
   - 打开页面右上角（或左侧）的 **“开发者模式” (Developer mode)** 开关。
   - 找到 **Tampermonkey** 扩展，点击 **“详情”**，确保已开启 **“允许运行用户脚本” (Allow User Scripts)**（以及按需开启“允许访问文件网址”）。

### 第二步：导入并启用脚本
1. 点击浏览器右上角扩展栏中的 **Tampermonkey 图标** -> 点击 **“添加新脚本...”**（或进入“管理面板”点击左上角 `+` 号）。
2. 将编辑器中默认自带的几行模板代码**全部清空**。
3. 打开项目中的 `web-clean-exporter.user.js`，**全选（Mac: `Cmd + A` / Windows: `Ctrl + A`）并复制（`Cmd + C` / `Ctrl + C`）**，粘贴到 Tampermonkey 编辑器中。
4. 按 **`Cmd + S`**（Windows 为 **`Ctrl + S`**）保存。
5. 返回“已安装脚本”列表，确认 **《网页长文/资料纯净提取与一键导出工具 (CleanReader & Exporter)》** 处于开启状态。
6. **跨域图片授权**：首次在目标网页点击导出 PDF / Word 时，若 Tampermonkey 弹出跨域请求提示，请点击 **“始终允许此域名”** 或 **“始终允许所有域名”**，以确保外链公式图片和配图能够正常内嵌到导出文件中。

## 📖 二、插件完整使用指南

安装完成后，打开任意新闻长文、技术文档或在线试卷网页（如 `zujuan.xkw.com` 组卷网等），页面**右下角**会自动出现蓝色的 **`📥 提取/导出`** 悬浮按钮（也可随时按快捷键 **`Alt + R`**，Mac 为 **`Option + R`** 快速开关纯净视图）。

点击 **`📥 提取/导出`** 按钮，会展开包含以下 6 项功能的菜单面板：

### 1. 📖 纯净阅读模式（最推荐，先预览再导出）
- 自动识别网页核心正文或试卷题目区域，剔除顶部导航、左侧广告栏、右侧推荐/试题统计栏、评论区以及“试卷分析/细目表”弹窗。
- 自动保留标题层级、段落、行内数学公式图片（与题干同行垂直对齐）、独立配图、数据表格，并自动去掉选择题排版表格的多余框线和题目外层卡片阴影。
- **顶部工具栏进阶操作**：
  - **`🔍 深度提取(含隐藏/伪元素)`**：当页面包含默认折叠的隐藏解析（`display: none` / `visibility: hidden`）或由 CSS `::before` / `::after` 伪元素生成的内容时，点击一键还原拼接。
  - **`🔼 扩大范围`**：如果自动识别只选中了某一道题或某一个小节，点击一次即可向上扩大一层父容器（直到囊括整份试卷）。
  - **`🖼️ 仅提画布页`**：针对采用整页 `<canvas>` 画布渲染的在线文档阅读器，一键仅提取已渲染并滚动缓存的文档画布页。
  - **`🎯 手动选区`**：重新用鼠标在原网页上精准框选任意区域。
  - **`✏️ 微调编辑`**：开启后整张白底预览纸变为可编辑状态，可直接用鼠标选中并删除不需要的段落、标题或水印文字，微调满意后再导出。

### 2. 🔍 深度提取 (含隐藏/伪元素)
- 递归遍历目标 DOM 容器，无视 `display: none`、`visibility: hidden`、`opacity: 0` 等 CSS 隐藏状态，同时读取 `getComputedStyle(el, '::before' / '::after').content` 伪元素文本及所有图片/懒加载图片地址，按原 DOM 顺序拼接为完整 HTML 供预览和导出。
- 开发者也可在浏览器 `F12` 控制台直接调用全局函数 `window.extractAllDomWithHiddenAndPseudo(document.body)` 获取完整 HTML 字符串。

### 3. 🎯 手动点选提取区域（万能精准模式）
- 当遇到排版非常特殊的网页、自动识别不够准确时使用：
  1. 点击 **`🎯 手动点选提取区域`**，移动鼠标时网页区块会出现**蓝色虚线高亮框**。
  2. 将鼠标移到任意题目或正文区域上，**按键盘 `↑`（上方向键）或 `W` 键**，可将蓝框逐层向上扩大到父容器（例如从“单道题”扩大到“整张试卷”）。
  3. 框选满意后**单击鼠标左键**，即可直接进入纯净预览并导出（按 `ESC` 键可随时取消）。

### 4. 📄 下载 PDF / 📝 下载 Word / 🖨️ 系统打印 (另存为高清 PDF)
三种导出方式可根据需求自由选择：

| 导出方式 | 实现机制 | 适用场景与特点 |
| :--- | :--- | :--- |
| **🖨️ 系统打印 / 另存PDF（推荐）** | 动态构建独立隔离的 A4 `iframe` 打印视图并调起 `print()` | 在打印弹窗中选择 **“另存为 PDF”**，导出的 PDF 为**矢量文字、放大不模糊、体积最小、数学公式和排版最精准**。 |
| **📄 下载 PDF** | 基于 `html2pdf.js` (`html2canvas` + `jsPDF`) 前端直接渲染 | 无需弹出系统打印窗口，一键直接下载 `.pdf` 文件，已配置防跨页文字腰斩、防图片截断及跨行公式防遮挡处理。 |
| **📝 下载 Word** | 自动将所有跨域图片与公式转为内嵌 Base64 并封装 MSO Word 文档 | 导出为 `.doc` 文件，可用 Microsoft Word 或 WPS 直接打开进行**二次编辑、增删题目或重新排版**。 |

## 💡 三、实用技巧与注意事项

1. **懒加载网页请先滚动到底部再导出**：许多题库和文档网页采用图片/画布懒加载（滑到下方才会加载第 10~21 题的公式图片或画布）。导出前建议**先用鼠标滚轮把整页从头到尾浏览一遍**，让所有可见内容完整加载后再点击导出。
2. **仅限提取网页已加载内容**：本脚本为纯前端 DOM 解析与排版导出工具，仅处理服务器已经下发并呈现在您浏览器中的网页内容；对于需要服务端鉴权或未下发的付费折叠页面，请通过平台官方渠道获取。
3. **无插件本地快速体验**：直接用 Chrome / Edge 双击打开项目目录下的 `demo-test.html`，即可在不安装 Tampermonkey 的情况下体验完整提取与导出功能。
